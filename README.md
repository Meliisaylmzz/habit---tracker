# Habit Tracker

C# ve .NET MAUI ile geliştirdiğim, günlük alışkanlıkları takip eden bir uygulama. C# öğrenirken adım adım geliştirdiğim bir proje.

![Ana ekran](ana-ekran.png)

## Özellikler

- Yeni alışkanlık ekleme
- Alışkanlığı yapıldı olarak işaretleme
- Alışkanlık silme
- Verilerin SQLite ile cihazda kalıcı saklanması (uygulama kapanınca veriler kaybolmaz)
- Kart tasarımı ve otomatik karanlık mod desteği

## Kullanılan teknolojiler

- C#
- .NET 8
- .NET MAUI
- SQLite (sqlite-net-pcl)

## Nasıl çalıştırılır?

1. Visual Studio'yu kur ve kurulumda **.NET Multi-platform App UI development** iş yükünü seç.
2. Repoyu indir ve `HabitTracker.sln` dosyasını Visual Studio ile aç.
3. Çalıştırma hedefini **Windows Machine** yap ve **F5** tuşuna bas.
